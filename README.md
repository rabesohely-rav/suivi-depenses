suivi des dépenses autres qu'hébergement
Suivi des dépenses
Application simple de suivi des dépenses et retraits, utilisable directement dans un navigateur.
Fonctionnalités
Saisie de dépenses et retraits
Validation du statut "Payé"
Calcul automatique des totaux
Conversion EUR / Ariary
Sauvegarde locale des données
Utilisation
Ouvrir le fichier index.html dans un navigateur
Saisir les dépenses
Les données sont sauvegardées automatiquement
Publication
Le site est publié via GitHub Pages.
Limites
Les données sont sauvegardées uniquement dans le navigateur (localStorage).
Elles ne sont pas synchronisées entre appareils.
